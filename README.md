<h2 style="text-align: center; color:#9c1de0;"> Proyecto: Sistema de Gestión de la Clínica Julieta Lanteri </h2>

> Este proyecto tiene como objetivo desarrollar una aplicación web para la gestión de pacientes y especialistas en la Clínica Julieta Lanteri, utilizando Angular como tecnología principal. 
> En la aplicación, los pacientes pueden registrarse, gestionar sus datos personales y acceder a sus historiales  médicos, mientras que los especialistas pueden administrar sus citas, consultas y perfiles profesionales. 
> Además, el sistema permite a los administradores gestionar a los usuarios, verificar la disponibilidad de los especialistas.

> El sistema también está integrado con Firebase para la autenticación de usuarios y el almacenamiento de datos en tiempo real. Los usuarios pueden registrarse de manera segura, iniciar sesión, y mantener actualizada su información a través de formularios interactivos con Angular Reactive Forms.
> El sistema tiene como objetivo optimizar la atención médica, facilitando la gestión de pacientes y profesionales de manera ágil y eficiente, al tiempo que proporciona una plataforma accesible y fácil de usar para todos los usuarios de la clínica.
